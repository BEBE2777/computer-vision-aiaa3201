## Conditions

- Host `ddcloud-icZMozpoz5`, NVIDIA RTX A6000, torch 2.7.1+cu126 / CUDA 12.6
- 3 timed passes over 180 images, 8 warm-up iterations discarded
- faiss/MKL threads pinned to 1, torch.set_num_threads(1), batch size 1
- CUDA allocator: weights 576 MiB, peak allocated 655 MiB, peak reserved 724 MiB

**Scope.** One test image end to end: decode, resize/normalise, upload, backbone forward, 1-NN over the reference bank, top-1% pooling, and the distance-map resize used for pixel AUROC. Excludes the one-off reference-bank construction (K references x 8 rotations) and excludes the VLM branch, which its owner times separately.
