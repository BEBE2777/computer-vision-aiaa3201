- 观察到 FPR=0 的类别为 **3/6**（cashew、chewinggum、fryum）。cashew 的召回率只有 0.256：该校准图的 fc_conf 离散度异常大
  （std≈1.96，其余类 0.4–1.9），95% 分位阈值被拉得过高（22.09，远高于其
  正常分数主体）。这是**校准分位数规则在重尾校准分布上的弱点**，不是分数
  无区分度（该类 AUROC 0.932 正常）。
- JSON 自由生成读出在 696 张上仍然退化：decision 674 OK / 22 NG，
  anomaly_score 仅 7 个唯一值（0.0–0.8）。candle 类分数无方差、AUROC 按本项目规则记为无定义；
  其余五类 AUROC 为 0.506–0.583。由于一类无定义，不报告六类宏平均。与 v1/v2/v3 一样，
  自由生成分数仍未形成稳定读出。

- 用同一图像做类别×标签分层的配对 bootstrap（20,000 次），Qwen−DINO 宏 AUROC
  差值为 +0.0262，95% CI [+0.0035, +0.0493]；Qwen−CLIP 为 +0.1045，95% CI
  [+0.0731, +0.1370]。这反映当前 696 张、1-shot/seed0 条件下的图像抽样差异，
  不包含 shot、参考 seed 或数据集变化。不能用两个单独 AUROC 区间是否重叠来代替配对差值检验。
- 明细与逐图分数：`matched_baselines_v4.json`（来源：E1 dump
  `e1_{dino448,clip448_L9}_nomask.json`，refs 与归档同规则）。

FPR/召回率区间使用双侧 Clopper–Pearson 精确二项区间。零误报不等于真实 FPR 确定为零：0/28 的 95% 上界为 0.123。完整统计审计见 `reviewed_statistics_v4.md`。Qwen 阈值实现取 20 个校准分数中索引 19（最大值）；E1 DINO/CLIP 使用 `numpy.percentile(..., 95)` 线性插值。校准图片相同，但有限样本分位数估计器不同，因此 FPR/召回率应分别作为实测 operating point 报告。

## 限制（必须与结果一起读）
1. **方向非盲**：fc_conf 的符号来自 v2 pilot 的观察，v3/v4 是同方向的推广验证；
   不是盲测。
2. 本轮是 1-shot / seed 0 的单一配置；未测 2/4/8 shot 与其它 seed。
3. 对照的 DINO/CLIP 数字是**同一 696 张子集**上的估计，不是其完整网格口径，
   不与论文主表直接混排。
4. 阈值规则（校准 95% 分位）是预先冻结的第一版规则；cashew 的低召回暴露了
   它对重尾校准分布敏感——**未做任何事后阈值调整**，如实报告。
5. 结论只针对本 manifest 实际评测的 696 张子集。
6. `fc_conf` 是两个完整 JSON 候选补全的序列对数概率差；候选同时改变 `decision` 和 `anomaly_score`，因此本结果尚不能单独归因于 OK/NG 判决字段。可把“只改变 decision 字段”的评分作为后续独立消融。

## 结论
在 696 张此前从未参与任何 Qwen 实验的 VisA 测试图上（1-shot/seed 0），Qwen2-VL-7B
的 forced-choice 序列对数概率（预定方向 fc_conf）取得宏平均 AUROC 0.958
[0.942, 0.971]。本子集上的配对 bootstrap 差值区间分别为 Qwen−DINO [+0.0035, +0.0493]、
Qwen−CLIP [+0.0731, +0.1370]；它们不包含 shot、seed 或数据集变化：
固定校准阈值下 3/6 类观测 FPR=0；其精确二项区间仍反映有限样本不确定性。除
cashew 外，各类召回率为 0.846–0.949；cashew 因阈值被重尾校准分布抬高仅 0.256。
自由生成 JSON 读出依旧退化。Qwen+DINO 融合仅为同一 v4 子集上的事后探索。
**尚未做**：其它 shot/seed、方向更改、prompt 修改、独立图片上的融合确认。
