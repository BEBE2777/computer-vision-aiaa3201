## A. Part 2 video script (~55 s, 150 words)

> For Part Two, we reproduce AnomalyDINO, a few-shot anomaly detection method
> built on DINOv2. It needs only a handful of *normal* reference images — no
> defect examples at all. Each reference is resized to 448 by 448 and passed
> through a frozen DINOv2 Vision Transformer, which outputs patch-level
> features. These features form a memory bank of normal appearance. For a test
> image, every patch is matched to its nearest neighbor in this memory bank,
> and that distance becomes the patch-level anomaly score. We pool the top one
> percent of patch distances into one image-level score, and the full patch
> distance map is upsampled into a pixel-level heatmap. As preliminary
> evidence — a single seed-zero run on the six VisA categories — the official
> pipeline reaches 94.6 percent image AUROC with one reference image, and 96.2
> with eight, while pixel AUROC stays around 98 percent. The full multi-seed
> evaluation is in progress.

## B. Part 3 plan script (~35 s, 95 words)

> Our Part One template baseline is highly sensitive to object position,
> background variation, and alignment. And AnomalyDINO scores with only the
> final-layer features of DINOv2, which may miss small local textures. Our
> planned improvement is multi-layer feature fusion: intermediate transformer
> layers capture fine local texture, while the final layer contributes semantic
> stability; we combine them with per-layer normalization. We will compare
> against unmodified Part Two on the same VisA data, the same reference
> filenames, and the same shots and seeds, reporting image AUROC, pixel AUROC,
> runtime, and GPU memory. To be clear: this is a plan, not a conclusion.
